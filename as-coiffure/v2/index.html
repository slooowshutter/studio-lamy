Le quartier

Vauban-Esquermes, quartier traditionnellement étudiant, dominé par l’Université catholique depuis 1875.

La place Catinat en fait partie. Dans le quartier aussi : la Citadelle, le Bois de Boulogne, le Jardin Vauban. La rue Colbert, qui donne sur la place, a été percée dans les années 1850 pour ouvrir une communication directe avec le centre de Wazemmes. La page Planity du salon cite aussi l’ICAM et le campus Saint-Raphaël, tout proches.

Sources : Wikipédia, « Vauban-Esquermes » ; page Planity du salon ; registre des entreprises.
