06 · Repères

À compléter avec vous.

Le nom et le décor visibles sur Planity donnent un premier point d’appui. La version finale se valide avec le salon.

Ce qui reste à préciser :

  • La forme officielle du nom et le logo.
  • Les couleurs du salon : le rose doux, les fauteuils noirs et le bois clair vus sur Planity sont des repères de décor, pas une charte officielle.
  • Les horaires, le numéro de téléphone et les tarifs actuels.
  • La carte complète et les détails de prise de rendez-vous.
