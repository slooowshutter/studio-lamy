# Stageshow — transposition locale

Référence consultée : `~/.claude/skills/stageshow/examples/static-card/`, puis craft, framing et bento.

Retenu : hiérarchie entre un sujet dominant et un panneau attaché à son bord, texte réel seulement sur le sujet, action complète visible, recomposition étroite à taille native.

Adaptation : ellipses CSS abstraites inspirées des soins des pieds en balnéo, panneau de sélection utile, sans faux client ni navigateur. Le panneau mène à la simulation réelle de cette page. Ce n’est pas une reproduction de matériel du salon.

Composition examinée dans le code à 1440 et 390 px. Sous 370 px, davantage de hauteur protège la légende ; le calendrier passe sur trois colonnes. Mouvements limités à transform/opacity, pas de boucle. Version statique sous reduced-motion ; les actions clavier restent instantanées.

Vérifié : HTML/CSS/JS statiques, contrastes, syntaxe et 269 vérifications de comportement. Pas de capture, vidéo, installation de dépendance, exécution du kit React ou essai navigateur. Aucune assertion de réussite du script de film Stageshow.
